# CODE QUEST V4 · Ingeniería en Sistemas PUCE

Versión 4.1.0. Aplicación educativa para la casa abierta.

- [Abrir e instalar](https://thesteppenwolf.github.io/code-quest-puce-v4/)
- [Vista para celular](https://thesteppenwolf.github.io/code-quest-puce-v4/ver-celular.html)

## Interfaz simplificada

Instrucciones breves, bloques con icono y nombre, y ayuda contextual en el botón de información. Conserva la letra grande, la música opcional y los cuatro accesos: Inicio, Retos, Entrena IA y Tú vs la IA.

Se mantienen los retos aleatorios, el entrenamiento interactivo y la comparación con la IA. El enlace y el QR de V4 siguen vigentes. V2 y V3 conservan sus archivos y direcciones.

## Instalación

Android: abrir en Chrome y elegir **Instalar aplicación** o **Agregar a la pantalla principal**. iPhone: abrir en Safari y usar **Compartir → Agregar a Inicio**. Después de la primera carga, el juego puede usarse sin conexión.
